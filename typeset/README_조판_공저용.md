# ROS2 첫걸음 — 조판 스킬 (공저용)

원고(.md)를 부크크 B5 hwpx로 조판하는 도구 모음입니다. 조판은 이수미가 일괄 진행하는 게
기본이지만, 직접 돌려 보고 싶으면 이 키트로 가능합니다.

## 준비

- Python 3.9+ (외부 패키지 불필요 — 표준 라이브러리만 씀)
- 한글(HWP)은 최종 확인용. PDF 렌더 스크립트만 한글 COM이 필요합니다(윈도우).

## 들어 있는 것

```
scripts/            조판 도구 (py)
template/           ROS2 B5 템플릿 (3장 토픽 조판본 — 스타일·판형 기준)
SKILL.md            조판 파이프라인 전체 문서 (다른 책 내용도 섞여 있음, 참고용)
README_조판_공저용.md  이 파일
```

## 기본 순서 (원고 .md → B5 hwpx)

```bash
# 1) 변환  (템플릿·charmap 반드시 이대로)
python scripts/md2hwpx.py \
  --template "template/ROS2_B5_템플릿_3장토픽.hwpx" \
  --charmap "h1:43,h2:17,h3:7,bold:13,body:11,quote:9" \
  --out 04_서비스.hwpx  04_서비스.md

# 2) 검증 (마지막 줄 VALID HWPX 확인)
python scripts/validate_hwpx.py 04_서비스.hwpx

# 3) 한글로 직접 열어 확인
```

- **판형이 B5(53291×74551)로 나오는지 꼭 확인하세요.** 다른 템플릿을 쓰면 판형이 틀어져
  합본이 안 됩니다(2·6장이 지금 이 문제로 재조판 대상입니다).
- charmap은 위 값 그대로 쓰세요. `##`=절 제목(17), 본문=11, 캡션=9 입니다.

## 코드박스 정규화 (코드 있는 장은 필수)

md2hwpx는 코드펜스를 **1열 표**로 만듭니다. 표는 셀 패딩 때문에 코드가 좌측 액센트바에서
떨어지고 폭이 불규칙해 보입니다. 코드 스타일(Consolas + 좌측바)이 입혀진 뒤 이걸 돌리면
**테두리 문단**으로 바뀌어 코드가 바에 밀착하고 박스가 본문폭에 규칙적으로 맞습니다.

```bash
python scripts/hwpx_code_boxes.py 04_서비스.hwpx
```

> 코드 스타일 주입(Consolas charPr + 주황 좌측바 borderFill)과 간지·고딕 절제목은
> 이수미가 일괄 적용합니다. 원고만 규칙대로 주시면 나머지는 맞춰집니다.

## 유용한 도구

| 스크립트 | 용도 |
|---|---|
| `hwpx_text.py` | hwpx 본문을 평문으로 추출 (교정·금지어 grep) |
| `hwpx_outline.py` | 목차(부/장/절)·글자모양 일람 추출. 처음 보는 hwpx는 `--analyze` 먼저 |
| `clean_ai_traces.py` | AI 말투·금지 표현 점검 (조판 전 0개 확인) |
| `validate_hwpx.py` | 출력 hwpx 무결성 검증 |
| `strip_linesegs.py` | 외부 편집 후 한글 "변조 가능성" 경고 뜰 때 |

## 주의 (안 지키면 한글이 파일을 안 엽니다)

- hwpx를 파이썬으로 직접 고쳤다면 `<hp:linesegarray>`를 전부 지워야 합니다
  (`strip_linesegs.py`). 안 그러면 한글이 "문서가 손상되었거나 변조되었을 가능성" 경고로
  파일을 아예 안 엽니다.
- 원고 md에서 **이미지·각주·중첩 리스트**는 피해 주세요(조판에서 깨집니다). 그림은
  `그림 N-N. 설명` 캡션 자리만 남기고 실제 파일은 따로 주세요.

문의는 이수미에게.
