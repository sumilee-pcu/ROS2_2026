## 4. 문체 규칙

문장 구조의 기준은 3장(토픽)이고, 어미는 평서문으로 통일한다.

- **평서문(한다체)** 으로 쓴다. `~합니다`가 아니라 `~한다`. (예: 노드를 만든다. 메시지를 발행한다.)
  - 기존 원고가 경어체(합니다체)면 평서문으로 맞춰 고친다.
- **한 장(章) 뼈대** — 아래 순서를 그대로 쓴다.
  1. `제N장 제목` (대표 제목)
  2. 도입 문단 2~3개 (앞 장과 잇고, 이 장에서 무엇을 하는지)
  3. **이 장에서 다루는 내용** — 불릿 4~6개
  4. **학습 목표** — 불릿 4~6개 (`~할 수 있다`)
  5. `N.1`, `N.2` … 절 (통신 모델 → 실습 → CLI 순)
  6. **정리** — 이 장 핵심 3~5줄
  7. **핵심 용어** — 용어: 한 줄 설명
  8. **연습문제** — 3~5문항
- 절 안 실습은 번호 단계로 나눈다: `① 노드 파일 작성` `② 등록` `③ 빌드·실행` `④ 확인`.

### 금지 표현 (이수미 전 저작 공통 규칙)

원고·캡션·그림 라벨 어디에도 쓰지 않는다. 조판 전 grep으로 0개를 확인한다.

- **따옴표 금지**: 작은따옴표·큰따옴표와 구부러진 스마트따옴표를 전부 안 쓴다. 강조는 굵게·번호·머리말로 대신한다.
- **이모지·딩벳 금지**: 컬러 이모지와 이모지형 딩벳(체크·삼각·원·별 모양 기호 등)을 전부 뺀다. 화살표 →는 흐름 연결에만 쓴다.
- **단어 여정 금지**.
- **은유어 금지**: 관통·기둥·관문·척추·받친다·떠받친다·꿰다·흐른다(문장 서술)·뿌리·출발점, 그리고 박다·박히다(은유).

## 5. 코드·실습 규칙

전 장이 같은 워크스페이스와 패키지를 이어 쓴다. 새로 만들지 않는다.

| 항목 | 규칙 |
|---|---|
| 워크스페이스 | `~/ros2_ws` |
| 파이썬 패키지 | `my_py_pkg` (2장에서 생성) |
| C++ 패키지 | `my_cpp_pkg` (2장에서 생성) |
| 커스텀 인터페이스 | `my_robot_interfaces` (6장에서 첫 생성) |
| 표준 타입 | 6장 전까지는 `std_msgs` · `example_interfaces`만 쓴다 |

- Python과 C++를 나란히 제시한다(같은 기능을 rclpy → rclcpp 순).
- 6장 전 장(3·4·5장)은 커스텀 인터페이스를 만들지 않는다. 표준 타입으로 해결한다.
  - 3장 토픽: `example_interfaces/msg/Int64` 등
  - 4장 서비스: `example_interfaces/srv/AddTwoInts`
  - 5장 액션: `example_interfaces/action/Fibonacci`
- 코드는 실제로 빌드·실행되는 것만 싣는다. `colcon build --packages-select …` → `source install/setup.bash` → `ros2 run …` 흐름을 매번 명시한다.
- 노드 등록: 파이썬은 `setup.py`의 `console_scripts`, C++은 `CMakeLists.txt`의 `add_executable`+`install`+`ament_target_dependencies`, 의존성은 `package.xml`에 적는다.

### 그림·캡션
- 캡션 형식은 `그림 N-M. 설명` / `표 N-M. 설명`으로 쓴다(마침표까지). 본문에서 먼저 그림으로 보겠다고 예고한다.
- 개념 다이어그램은 조판 담당(이수미)이 일괄 생성한다. 원고에는 캡션 줄과 자리만 남긴다.

## 7. 조판 파이프라인 (조판 담당용)

- 스킬: `hwpx-book` (`C:\Users\user\.claude\skills\hwpx-book`).
- 템플릿은 3장 토픽 hwpx(B5 53291×74551, 정식 스타일)를 쓴다. 6장(파라미터) hwpx는 판형이 커서(59530×84190) 템플릿으로 쓰지 않는다.
- charmap: `h1:43,h2:17,h3:7,bold:13,body:11,quote:9`
  - `#`=제N장(1900 bold) / `##`=N.N 절(1100 bold) / `###`=박스 라벨·소절(1000 bold) / `**굵게**`·표머리=13 / 본문=11 / `>`=캡션(900)
- 변환:
  ```
  python scripts/md2hwpx.py --template "…3장_토픽.hwpx" \
    --charmap "h1:43,h2:17,h3:7,bold:13,body:11,quote:9" \
    --out 05_액션.hwpx  05_액션.md
  ```
- 검증: `python scripts/validate_hwpx.py 05_액션.hwpx` 로 `VALID HWPX`를 확인하고, 마지막에 한글로 직접 열어 확인한다.
- 함정: 기존 hwpx를 외부 편집하면 `linesegarray`를 전역 제거한다(스킬 함정 3). 이미지 추가 시 `content.hpf`에 `isEmbeded="1"`을 넣는다(함정 5).
